# Arcane Staff — мод для Minecraft 1.21.4 (Fabric)

## Что делает мод
- **Волшебный посох** с 6 заклинаниями: Огненный луч, Молния, Телепорт, Исцеление, Ледяная волна, Метеор.
  - ПКМ — применить заклинание, клавиша **Z** (или **R**) с посохом в руке — переключить заклинание.
- **Два новых моба** (Кристальный голем, Арканный скелет) со светящейся бронёй, «короной» и магическими эффектами.
  Не горят на солнце, роняют **Арканный кристалл**.
- **Арканный алтарь**: ПКМ по нему с 5 Арканными кристаллами в руке призывает босса (молнии, портальный вихрь).
- **Босс «Арканный Страж»**: 300 HP, огромный, в золотой короне и светящейся броне, с вращающейся аурой.
  Бьёт по площади (волна по земле), на 2/3 и 1/3 здоровья призывает Кристальных големов.
  Даёт 1500 опыта, роняет кристаллы и алмазы.
- **RPG-прокачка с тремя классами**: за убийство монстров даётся опыт → уровни (до 30) → очки навыков.
  Меню навыков — клавиша **K**, класс переключается стрелками **< >** (или клавишами ← →).
  Уровень и очки общие, их можно тратить в любом классе.
  - **Маг**: Сила магии, Быстрая магия, Молния, Телепорт, Исцеление, Ледяная волна, Мудрость (+15% опыта),
    **Метеор** (огненный шар с неба, мощный взрыв).
  - **Мечник** (с мечом в руке): Сила клинка, Железная кожа, Живучесть, Жажда крови,
    **Вихрь клинков [R]** (удар по кругу, враги подлетают), **Рывок клинка [Z]** (рывок сквозь врагов),
    **Грозовой клинок** (шанс молнии при ударе).
  - **Лучник** (с луком в руке): Меткость, Лёгкие ноги, Лёгкое падение, Огненные стрелы, Азарт охотника,
    **Прямой полёт** (стрелы без падения, со светящимся следом),
    **Град стрел [R]** (15 стрел веером), **Ливень стрел [Z]** (36 стрел с неба в точку прицеливания).
- **Достижения**: «Уничтожитель чанков» (метеор по 5+ монстрам), «Убийца Стража», «Ритуал призыва»,
  «Мастер трёх путей», «Легенда арканы» (30 уровень), «Небо в стрелах», «Танцор клинков».
- Прокачка сохраняется в мире и не пропадает после смерти.

## Как получить предметы
- Крафт посоха: 3 Арканных кристалла + 2 палки (схема: `CC_ / CS_ / S__`, C — кристалл, S — палка).
- Крафт алтаря: 5 Арканных кристаллов + 4 обсидиана (схема: `CCC / COC / OOO`, C — кристалл, O — обсидиан).
- Команды (работают без читов):
  - `/arcane staff` — выдать посох;
  - `/arcane xp 100` — добавить опыт магии (для показа прокачки);
  - `/arcane reset` — сбросить прокачку;
  - `/arcane boss` — призвать босса перед собой (без алтаря).
- Яйца призыва мобов и босса — в творческом режиме, вкладка «Яйца призыва».

## Что нужно, чтобы запустить в игре
1. Minecraft Java **1.21.4**.
2. Fabric Loader для 1.21.4 (https://fabricmc.net/use/installer/).
3. Fabric API для 1.21.4 (Modrinth или CurseForge) — положить в папку `mods`.
4. Файл мода `arcane-staff-1.0.0.jar` — тоже в папку `mods`.

## Как собрать мод (получить .jar)
### Вариант 1. Через GitHub, ничего не устанавливая
1. Создайте репозиторий на github.com и загрузите в него все файлы этого проекта (Add file → Upload files). Папка `.github` должна загрузиться вместе с остальными.
2. Откройте вкладку **Actions** → запустится сборка `build` (или нажмите Run workflow).
3. Через 3–5 минут откройте завершённую сборку и скачайте **Artifacts → arcane-staff-mod**. Внутри будет `arcane-staff-1.0.0.jar`.

### Вариант 2. На своём компьютере
1. Установите Java 21 (например, Temurin 21).
2. В папке проекта выполните: `gradlew build` (Windows: `gradlew.bat build`).
3. Готовый файл: `build/libs/arcane-staff-1.0.0.jar` (файл с `-sources` в конце не нужен).

## Сценарий показа преподавателю (3–4 минуты)
1. Создать мир в творческом режиме, выполнить `/arcane staff` и `/arcane xp 3000`.
2. Показать посох: ПКМ — огненный луч; **Z** — переключить заклинание (молния, телепорт, ледяная волна, метеор).
3. Вкладка «Яйца призыва» → призвать Кристального голема и Арканного скелета (светящаяся броня, частицы).
4. Нажать **K** → показать древо навыков, стрелками `<` `>` переключить классы Маг / Мечник / Лучник, вложить очки.
5. Взять меч: **R** — вихрь клинков, **Z** — рывок. Взять лук: **R** — град стрел, **Z** — ливень стрел.
6. Поставить Арканный алтарь (вкладка «Функциональные блоки»), ПКМ с 5 кристаллами — призыв босса.
7. Победить босса, показать достижения (клавиша L).

## Структура кода
- `arcane/item/` — посох и заклинания; `arcane/block/` — алтарь; `arcane/entity/` — мобы; `arcane/data/` — прокачка, навыки, способности классов, достижения;
- `arcane/net/` — обмен данными клиент ↔ сервер; `arcane/client/` — окно навыков и отрисовка мобов;
- `src/main/resources/` — тексты (ru/en), модели, текстуры, рецепт, добыча с мобов.
